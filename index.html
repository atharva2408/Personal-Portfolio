About me

Think twice, code once. I like systems where the data, the API and the interface are designed together. My working rule

For the past two years I’ve been a software engineer at Emergys Solutions, working top to bottom: React interfaces, Express and FastAPI services, and SQL Server underneath. The work I’m proudest of is making slow things fast and complicated things legible.

Lately that has moved toward agentic AI. I built a LangGraph workflow that classifies a question, retrieves the schema, writes and revises SQL, and lets teams swap the LLM behind it. Before that: Rust, Linux and Java internships, and a computer-vision system at Intel.

Next, I want the research side to catch up with the engineering. I’m seeking an MS in Computer Science to study ML, deep learning and agentic AI, with the aim of building AI that is egalitarian, accessible and transparent.
